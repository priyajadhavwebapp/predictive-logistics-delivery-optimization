# Phase 3 – Literature and Data Research

## Purpose
This phase establishes the research background and identifies a suitable public dataset.

## Research Topics
Research and document information about:
- Logistics and supply chain analytics
- Delivery performance measurement
- Predictive analytics in logistics
- Regression for delivery-time prediction
- Clustering for shipment segmentation
- Optimization in transportation and resource allocation

## Suggested Public Data Sources
- Kaggle logistics and supply-chain datasets
- UCI Machine Learning Repository
- Government open-data portals
- Other reputable public datasets

## Dataset Selection Checklist
Choose a dataset containing as many of these fields as possible:
- Order/shipment ID
- Order date
- Shipment date or delivery date
- Origin
- Destination
- Distance
- Quantity
- Weight
- Transportation/shipping mode
- Delivery status
- Delivery time or delay
- Transportation cost

## Research Notes
Record:
1. Dataset name
2. Dataset source
3. URL
4. Number of rows
5. Number of columns
6. Important variables
7. Dataset limitations
8. Why the dataset is suitable
