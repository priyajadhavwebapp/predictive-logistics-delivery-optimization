# Phase 8 – Data Science Methodologies

## 8.1 Regression
Regression can be used to predict delivery time from variables such as distance, weight, quantity, shipping mode and other available operational factors.

**Target:** Delivery Time

## 8.2 Clustering
Clustering can group shipments with similar characteristics.

Possible groups:
- Short-distance / low-weight
- Long-distance / high-weight
- High-volume shipments

## 8.3 Optimization
Optimization can be used to support:
- Vehicle assignment
- Route selection
- Capacity allocation
- Cost minimization
- Delivery-deadline management

## Proposed Workflow
Data → Features → Model → Evaluation → Business Interpretation → Logistics Strategy

## Note
Week 1 focuses mainly on planning and strategic methodology. Full predictive modeling can be implemented in later phases.
